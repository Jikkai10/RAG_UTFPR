# RAG para documentos da UTFPR

Chatbot com LLM que usa RAG para responder com base nos documentos oficiais da UTFPR.

- [`chatbot/`](chatbot/): API, pipeline do RAG, extração dos documentos e script de avaliação.
- [`frontend/`](frontend/): interface web (React + Vite).
- [`avaliacao/`](avaliacao/): perguntas e respostas de referência e a avaliação de cada fluxo.
